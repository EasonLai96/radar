# DSH 雷達｜2026-11-10（一）

## 1. llm 外掛支援 Fable 5.2

llm-anthropic 0.31 支援 Fable 5.2 與 Mythos 5.2。實測 max 推理等級耗盡 12.8 萬思考 token 而無法產出圖片，Fable 5、5.1 則正常。

> 💡 可用 llm 指令比較各推理等級的產出；max 等級需留意失敗。

[llm-anthropic 0.31](https://simonwillison.net/2026/Nov/9/llm-anthropic)｜Simon Willison｜評分 77（76 / 78）

## 2. DSH 側欄能所見即所得寫 .md

dsh-marktext 是 DSH 右側欄外掛，用 MarkText 的 muya 引擎讓 .md 檔直接所見即所得編輯，還能把選取文字引用到聊天，並匯出 PDF。

> 💡 寫專案 README 或筆記時不用看原始碼，選一段就能一鍵引用給 AI 討論。

[Roland0511/dsh-marktext](https://github.com/Roland0511/dsh-marktext)｜GitHub DSH 生態｜★410｜評分 76（78 / 74）

## 3. DSH 出現自媒體工作台插件

dsh-media-desk 是 DeepSeek Harness 的免費開源插件，記一句靈感就能生成腳本、標題、封面、配圖和分鏡。

> 💡 網頁版在手機瀏覽器也能開，想經營社群帳號，或研究 DSH 插件怎麼寫，都可以拿來參考。

[woniuniuniu/dsh-media-desk](https://github.com/woniuniuniu/dsh-media-desk)｜GitHub DSH 生態｜★667｜評分 71（67 / 76）

## 4. PulsoIcon：會動的圖示庫

PulsoIcon 收錄 9955 個動態圖示，每個都有專屬動作，hover 或 focus 時播放。React 版可直接取代 lucide-react，也支援 Vue、Svelte 等。

> 💡 做網頁或小遊戲介面時，改一行 import 就能讓圖示 hover 有動畫。

[CityPulso/PulsoIcon](https://github.com/CityPulso/PulsoIcon)｜GitHub 新專案｜★545｜評分 71（64 / 78）

## 5. Fable、Mythos 5.2發布

Anthropic 發表 Claude Fable 5.2 與 Mythos 5.2，但材料沒有內文，功能與規格不明。HN 上有 328 分、670 則留言。

> 💡 留言多達 670 則，可先看社群評價，再決定要不要拿來試做機器人。

[Claude Fable 5.2 and Mythos 5.2](https://www.anthropic.com/claude-fable-and-mythos-5-2)｜Hacker News｜評分 70（72 / 68）

## 6. Claude 用純JS寫出3D彩蛋

Simon Willison 用 Three.js 做海蛞蝓主題彩蛋，請 Claude Opus 5.5 改寫成純 Vanilla JS+WebGL，成功但程式碼不完全相同。

> 💡 證明 LLM 能跳過 Three.js 直接寫 WebGL，寫 3D 小遊戲可少裝一個函式庫。

[The Web Is More Than Enough, by Paul Ford](https://simonwillison.net/2026/Nov/9/hn-50421091)｜Simon Willison｜評分 69（63 / 76）
