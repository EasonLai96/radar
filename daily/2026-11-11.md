## 2. Chrome 開源現代 Web 指南 供 AI 代理使用

Chrome 與 Firefox、MDN、Edge 合作開源 200+ 篇現代 Web 實作指南，打包成 agent skill 與 CLI，約 7MB、搜尋約 10ms。

> 💡 讓 coding agent 改用 showModal()、field-sizing 等原生寫法，少寫 JS 與相依套件。

[Show HN: Get your coding agent off ~2019 JavaScript, onto modern web primitives](https://github.com/GoogleChrome/modern-web-guidance)｜Hacker News｜評分 75（72 / 78）

## 3. 提示說程式碼是它的，更會合併重複

Anthropic 在小型寫程式任務測試中發現，提示若寫明「這個程式庫是你的」，Claude Fable 5.2 合併重複程式碼的比例約一半，沒有這句話則不到一成。

> 💡 寫 Prompt 時可直接加上這句話，讓 AI 在開發中順手整理重複邏輯。

[Quoting Prompting Claude Fable 5.2](https://simonwillison.net/2026/Nov/10/prompting-claude-fable-52)｜Simon Willison｜評分 70（64 / 77）

## 4. DSH 技能：中文文案轉程式碼動畫

開源 DSH 技能 fy-code-animation，把中文文案、畫風與聲音做成前後連貫的程式碼動畫，支援 Remotion、Canvas 與 HTML。

> 💡 中文動畫不想淪為逐句貼圖的投影片，可參考它的語義分鏡流程。

[Akillll-DuoHe/fy-code-animation](https://github.com/Akillll-DuoHe/fy-code-animation)｜GitHub DSH 生態｜★308｜評分 68（65 / 72）
